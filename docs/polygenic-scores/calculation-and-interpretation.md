# Polygenic-score calculation and interpretation

Users explicitly select PGS IDs. An immutable local bundle records version, trait, primary citation, license, URL/hash, build, preparation pipeline, FASTA identity, exclusions, and artifact hashes. Catalog inclusion is not clinical endorsement. Target analysis never fetches resources.

M7 supports only GRCh38 autosomal diploid biallelic SNVs with additive weights and exact alleles. It defaults to observed M2 calls. Missing/incompatible markers retain reasons. Partial sums are debugging quantities, not complete scores. Reference z-scores and empirical midrank percentiles require an explicit exact-compatible aggregate distribution; cohort labels describe a study, not personal identity. Transportability varies with phenotype, study design, genotyping/imputation, LD/frequencies, environment, covariates, and healthcare context. This is research-oriented information, not diagnosis, advice, absolute risk, or treatment guidance.
